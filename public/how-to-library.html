How to add your Search Console and GA4 data

Moz shows one ranking page per keyword. Search Console shows every page Google tested for a keyword, with clicks and impressions, so it's what reveals real cannibalization. GA4 adds sessions per page so you can see which page is worth keeping. You'll put both in one Google Sheet with two free add-ons, download it, and upload it in Settings. About 5 minutes.

Prefer to have Claude do it? Download the Claude skill, add it in Claude (Settings → Capabilities → Skills → Upload skill), then ask: "Build my URL library sheet for example.com". With Claude in Chrome, Claude can click through the add-ons for you; otherwise it walks you through each step.

1. Search Console: query × page data

  1. Create a new Google Sheet (sheets.new) and name it, e.g. URL library – example.com.
  2. Install Search Analytics for Sheets: Extensions → Add-ons → Get add-ons, search for it, click Install and allow access with the Google account that can see your Search Console property.
  3. Open Extensions → Search Analytics for Sheets → Open Sidebar, then on the Requests tab set:
    • Verified site: your property (a domain property like sc-domain:example.com is best)
    • Date range: the last 3 months
    • Search type: Web
    • Group by: Query and Page (both, in that order)
    • Rows returned: as many as allowed (e.g. 100,000; larger sites can use 50,000)
    • Results sheet: a new sheet, rename it Search Console
  4. Click Request data. You'll get columns Query, Page, Clicks, Impressions, CTR, Position. Leave them as they are.

Don't use the Export button in Search Console's Performance report: it gives queries and pages separately, and the tool needs them paired (which pages show for which query).

2. GA4: sessions per page

  1. In the same Sheet, install GA4 Reports Builder for Google Analytics (Google's official add-on): Extensions → Add-ons → Get add-ons.
  2. Open Extensions → GA4 Reports Builder for Google Analytics → Create new report and set:
    • Account / Property: your site's GA4 property
    • Date range: last 365 days
    • Dimensions: pagePath (or landingPage if you prefer entrances)
    • Metrics: sessions
    • Limit: 100000
  3. Click Create report, then Extensions → GA4 Reports Builder → Run reports. A new sheet appears with the page paths and sessions.

3. Download and upload

  1. File → Download → Microsoft Excel (.xlsx). Both sheets go into one file.
  2. In the tool, open Settings → Add your Search Console and GA4 data → upload the file. It's read in your browser, saved there, and only sent to build your library: never stored on the server.
  3. Click Build the library. Rebuild monthly: re-run the add-on requests (both have a refresh/run option), download, upload, rebuild.
